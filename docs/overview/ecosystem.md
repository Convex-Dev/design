# Ecosystem Projects

Projects, tools and applications built on or around Convex. If you have a project, demo or idea to share with the ecosystem, pull requests against this page are welcome — the community-maintained [Awesome Lattice](https://brittleboye.github.io/awesome-lattice/) list is also a good home for anything lattice-related.

## Applications

Projects and apps intended for end users.

| Title | Summary | Status | Links |
|-------|---------|--------|-------|
| Convex Desktop | Full-featured desktop application and wallet, including a local peer, REPL and network explorer | Released (ships with [Convex releases](https://github.com/Convex-Dev/convex/releases)) | [Source](https://github.com/Convex-Dev/convex/tree/develop/convex-gui) |
| Paisley | User-owned P2P payment network | In development | [Website](https://www.paisley.io/) |
| Block Game | A Minecraft-inspired voxel game running on the CVM | Demo | [GitHub](https://github.com/mikera/blockgame) |
| Prediction market | AMM-based prediction market supporting arbitrary oracles | Proof of concept | [Source](https://github.com/Convex-Dev/convex/blob/develop/convex-core/src/main/cvx/convex/lab/prediction-market.cvx) |
| Convexity | Open-source Convex wallet built with Flutter | Dormant (last updated 2022) | [GitHub](https://github.com/Convex-Dev/convexity) |

## Getting listed

Open a pull request against [Convex-Dev/design](https://github.com/Convex-Dev/design) adding a row with your project's name, a one-line summary, an honest status, and a link. Projects at any stage are welcome — clearly labelled experiments included.
