Practical guides for building on Convex — from your first transaction to production peer infrastructure.

New here? The **[Quick Start](/docs/tutorial/quickstart)** deploys your first smart contract on a live network in under a minute, with no installation.

## Pick your path

### Application developer

Build apps that use Convex for state and transactions — web, mobile or backend services.

1. **[Networks](/docs/tutorial/networks)** — choose a network and get connected
2. **[Client SDKs](/docs/tutorial/client-sdks)** — TypeScript / JavaScript, Python or Java, each with its own quickstart
3. **[Recipes](/docs/tutorial/recipes)** — practical worked examples

### Smart contract developer

Build actors — Convex's smart contracts — and other on-chain logic: DeFi protocols, DAOs, autonomous services.

1. **[Convex Lisp](/docs/tutorial/convex-lisp)** — the on-chain language
2. **[Actor Development](/docs/tutorial/actors)** — concepts, building, deployment and upgrade
3. **[Local Testnets](/docs/tutorial/peer-operations/local-testnets)** — fast offline iteration

### Agent developer

Connect AI agents to real economic state.

1. **[AI Agents](/docs/tutorial/agents)** — why Convex suits agentic systems
2. **[MCP Integration](/docs/tutorial/agents/mcp)** — connect any MCP-compatible agent to a peer
3. **[Agent Accounts](/docs/tutorial/agents/account-management)** and **[Agentic Economics](/docs/tutorial/agents/agentic-economics)** — keys, funding and agent-to-agent commerce

### Peer operator

Run peer infrastructure and participate in consensus.

1. **[Peer Operations](/docs/tutorial/peer-operations)** — the complete operations guide
2. **[Staking](/docs/tutorial/peer-operations/staking)** — economic requirements
3. **[Security](/docs/tutorial/peer-operations/security)** — secure operations

## Client SDKs

Official client libraries, each with a copy-paste quickstart:

- **[TypeScript / JavaScript](/docs/tutorial/client-sdks/typescript)** — `npm install @convex-world/convex-ts`
- **[Python](/docs/tutorial/client-sdks/python)** — `pip install convex-sdk`
- **[Java](/docs/tutorial/client-sdks/java)** — `world.convex:convex-java:0.8.10`

For command-line interaction, see the [Convex CLI](/docs/products/convex-cli).
